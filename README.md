# Agent Climate

温哥华三维污染交互场景。Blender 城市资产、WebGL 体积浓度与实际粒子路径。

**网站：** https://baiming-zhang.github.io/Agent_climate/

拖动旋转、滚轮缩放、点击查询。播放默认15秒，可调节时长与烟羽颜色。

**计算与结果：** https://baiming-zhang.github.io/Agent_climate/results/ 。含模拟步骤、238条留出报告、各GPU版本原门验证、第一版以来的改进及CSV/JSON下载。该页为带UTC时间戳的报告快照。

本页发布已完成的2021年12月历史案例，包括独立120秒三源条件释放和71.5小时区域输送。未来30天试验未通过资格验证，未作为本页数据。原历史试验的预设成功门也未通过；可视化不代表预测精度已达标。

- 区域地表查询直接读取原生0–20m层源贡献，时空双线性/线性插值；不含均匀背景。范围外返回空值。
- 近场地表读数为Gaussian模型在局部平地0–20m的10点垂直求积。
- 显示烟羽用浓度控制透明度，SO₂本身无色。只插值物理标量/位置，不混合相邻图像。
- 保留295,252栋建筑轮廓与简化地标；Draco压缩只用于展示几何。高程显示×1.8。
- Briggs渐进浮升、Hanna/OU近场扩散与区域WRF/FLEXPART不是建筑尺度CFD。

静态文件直接由GitHub Pages发布，不依赖本地API服务。可用任意HTTP服务器本地运行。

第三方来源与许可见 [THIRD_PARTY.md](./THIRD_PARTY.md)。
